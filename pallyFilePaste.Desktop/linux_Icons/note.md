# note
***use the icons folder for the linuxdeploy's `AppDir/` folder when you want to create an appimage***

to create the folder structure for the `AppDir/`, run this command:
```bash
./linuxdeploy-x86_64.AppImage --appdir AppDir
```
then replace the `icons/` folder generated by linuxdeploy with the `icons/` folder from this repository
